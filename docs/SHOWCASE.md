# Final presentation checklist

- [ ] State the problem, users, and intended use.
- [ ] Name the dataset and the population it represents.
- [ ] Explain the split and show how you prevented leakage.
- [ ] Compare a baseline with your chosen model using a suitable metric.
- [ ] Show a working app or reliable demonstration and how to run it.
- [ ] Mention two limitations or failure cases.
- [ ] Provide a GitHub README and model card.
